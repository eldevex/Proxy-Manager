# Proxy Manager

Менеджер подписок для прокси с поддержкой автообновления, конвертации JSON-конфигов и проксированием служебных заголовков.
- **Демо:** [Proxy Manager](https://bobr-hwid.alwaysdata.net/sb/)

- **Telegram:** [t.me/bober41](https://t.me/bober41)

---

## Возможности

### Управление подписками
- Создание именованных подписок с уникальными хеш-ссылками
- Ручное добавление прокси-ссылок или импорт из внешней подписки
- Редактирование содержимого, очистка, добавление из других источников

### Автообновление
- До 5 источников на подписку
- Настраиваемый период: от 1 часа до 24 часов
- Автоматическое обновление при запросе клиентом по ссылке
- Ручное форсирование обновления

### Поддерживаемые протоколы
- VLESS (с конвертацией из JSON outbound)
- VMess, SS, SSR, Trojan
- Hysteria / Hysteria2
- TUIC, WireGuard

### Парсинг и конвертация
- JSON-конфиги с outbounds (Xray-формат)
- Base64-закодированные подписки
- Прямые ссылки построчно
- Проксирование заголовков `subscription-userinfo` при единственном источнике

### Мониторинг источников
- Отображение трафика: upload, download, total, remaining
- Прогресс-бар использования
- Дата истечения подписки
- Время последнего обновления

### Дополнительно
- Дедупликация прокси-ссылок
- Сохранение комментариев из подписок
- Публичные подписки (видны всем пользователям)
- Пользовательский HWID Seed для генерации заголовков
- Темная и светлая тема
- Мультитенантность: каждый пользователь видит только свои подписки

## Требования

- PHP 7.4+
- Расширение `curl`
- Права на запись в директорию скрипта

---

## Установка

1. Скопируйте `index.php` на сервер
2. Убедитесь, что директория доступна для записи (создается `subs/`)
3. Откройте в браузере

Авторизация при первом входе создает аккаунт автоматически.

---

## Структура данных

```

subs/
├── .registry.json      # реестр подписок
├── .settings.json      # настройки пользователей
├── .users.json         # база пользователей
└── [hash].txt          # файлы подписок

```

## API Endpoints

| Метод | Параметры | Описание |
|-------|-----------|----------|
| `POST` | `action=login` | Авторизация / регистрация |
| `POST` | `action=save_sub` | Создание подписки |
| `POST` | `action=get_subs` | Список своих подписок |
| `POST` | `action=get_public_subs` | Список публичных подписок |
| `POST` | `action=get_content` | Получение содержимого подписки |
| `POST` | `action=save_all` | Сохранение подписки с настройками |
| `POST` | `action=update_sub` | Обновление содержимого |
| `POST` | `action=clear_sub` | Очистка файла |
| `POST` | `action=append_sub` | Добавление из внешней подписки |
| `POST` | `action=delete_sub` | Удаление подписки |
| `POST` | `action=update_flags` | Обновление флагов |
| `POST` | `action=update_auto` | Обновление настроек автообновления |
| `POST` | `action=force_update` | Принудительное обновление |
| `POST` | `action=get_sources_info` | Информация об источниках |
| `POST` | `action=get_settings` | Получение настроек пользователя |
| `POST` | `action=save_settings` | Сохранение настроек пользователя |
| `GET` | `?i=hash` | Выдача подписки клиенту |
| `GET` | `?url=encoded_url` | Проксирование внешней подписки |

<summary><strong>Инструкция по использованию</strong></summary>

### Регистрация и вход

При первом входе введите любой логин (a-z, 0-9, _, -, макс. 32 символа) и пароль. Аккаунт создается автоматически.

### Создание подписки

1. Перейдите на вкладку **Создать**
2. Укажите название
3. Выберите режим:
   - **Ручной** — вставьте прокси-ссылки
   - **Импорт** — укажите URL подписки (однократно)
   - **Автообновление** — укажите URL источников и период
4. Настройте флаги: дедупликация, комментарии, публичность
5. Нажмите **Сохранить**

### Использование ссылки

Скопируйте ссылку из карточки подписки и вставьте в клиент. При каждом запросе файл обновится автоматически, если прошел заданный период.

### Мониторинг источников

На автообновляемых подписках доступна кнопка **Инфо** — показывает трафик и срок действия каждого источника.

### Настройки пользователя

В шапке кнопка **Настройки** позволяет задать свой HWID Seed. Если оставить пустым, используется системный.
